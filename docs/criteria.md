# 기준 문서 (calc.js / index.html / app.js 공통 기준)

원본: data/programs/RULES.md, 2024.csv, 2025.csv, 2026.csv, errors.csv (수정 금지)

## 1. 입력 형식
- 열 이름·순서: `연도,사업ID,사업명,분야,지역,참여자수,수료자수` (헤더 1행 필수)
- UTF-8, BOM(EF BB BF) 있어도 없어도 읽는다. 첫 열 이름에서 BOM 제거.
- 여러 파일 합치기: 파일 선택 순서대로 파일을 이어 붙이고, 각 파일 안에서는 행 순서대로. 이 순서가 "첫 행" 판단 기준.
- 행 번호는 원본 파일 기준(헤더가 1행, 첫 자료 행이 2행). 빈 줄은 건너뛴다.

## 2. 행 검증 (순서대로, 처음 걸린 이유 하나만 표시)
1. 숫자 누락: 참여자수 또는 수료자수가 빈 값 -> `숫자 누락`
2. 정수 아님/음수: 0 이상의 정수가 아님(소수·문자·음수) -> `정수가 아니거나 음수`
3. 수료자 초과: 수료자수 > 참여자수 -> `수료자가 참여자보다 많음`
4. 중복: 앞 단계를 통과한 행 중 (연도+사업ID)가 이미 "유효한 행"으로 남아 있으면 -> `중복(연도+사업ID)`
   - 무효로 제외된 행은 중복 판정의 "첫 행"이 되지 않는다. 유효한 첫 행만 남기고 이후 같은 키는 제외.
- 제외 행은 `원본 파일명 · 행 번호 · 이유`를 함께 목록으로 표시. 제외 행은 요약·차트·표·CSV에서 모두 뺀다.

## 3. 0명 행
- 참여자 0·수료자 0은 유효 행으로 유지(제외 아님).
- 개별 수료율 `계산 불가`, 판정 `계산 불가`, 이유 문구 `참여자 0명으로 수료율 계산 불가`. 주의로 세지 않는다.
- 필터 결과 전체 참여자 합계가 0이면 전체 수료율도 `계산 불가`(연도별 수료율도 해당 연도 참여자 합이 0이면 계산 불가, 꺾은선에서는 점 생략).

## 4. 수료율과 판정
- 수료율 = 합산 수료자 ÷ 합산 참여자 × 100. 사업별/행별 비율의 단순 평균 금지.
- 표시: 소수 1자리 + `%` (예: 83.1%). 내부 계산은 반올림하지 않은 값으로 비교.
- 주의 판정: 수료율 < 기준. 기본 기준 70, 화면에서 변경 가능. 정확히 기준값이면 주의 아님(`정상`). 판정 값: `주의` / `정상` / `계산 불가`.

## 5. 요약 6개
1. 참여자 합계: 필터 유효 행 참여자수 합
2. 수료자 합계: 필터 유효 행 수료자수 합
3. 전체 수료율: 수료자 합계 ÷ 참여자 합계 × 100 (참여자 합계 0이면 계산 불가)
4. 사업 수: 필터 유효 행의 고유 사업ID 수
5. 선택 연도 수: 필터에 선택된 연도 중 유효 행이 있는 연도 수(전체 선택 시 데이터에 있는 연도 수)
6. 주의 항목 수: 개별 행 기준 판정이 `주의`인 행 수(계산 불가·정상 제외)

## 6. 차트·표·CSV
- 분야별 참여자(파이): 분야 고정 순서 교육 -> 일자리 -> 지역사회, 값은 참여자 합. 고정 색 제안: 교육 #2563eb, 일자리 #f59e0b, 지역사회 #16a34a. 필터로 합이 0인 분야도 범례에는 유지(값 0). 제목·단위(명)·범례·값·안내 문구 표시.
- 사업별 참여·수료(막대): 사업ID 오름차순, 사업별로 참여자 합·수료자 합 2개 막대. 고정 색 제안: 참여 #94a3b8, 수료 #0d9488. 같은 사업ID가 여러 연도면 합산.
- 연도별 수료율(꺾은선): 연도 오름차순, 각 연도 합산 수료자 ÷ 합산 참여자 × 100 (단위 %), 기준선(주의 기준) 표시 권장.
- 상세 표 열: 연도, 사업ID, 사업명, 분야, 지역, 참여자수, 수료자수, 수료율, 판정. 정렬은 병합 순서(파일 순서 -> 행 순서) 유지. 주의 행 강조.
- CSV 출력: 필터 후 유효 행만, 원본과 같은 7개 열·순서(`연도,사업ID,사업명,분야,지역,참여자수,수료자수`), UTF-8 BOM 포함, 수료율·판정 열 없음, 다시 읽으면 같은 검증을 통과해야 함. 쉼표·따옴표가 있는 값은 큰따옴표로 감싸고 내부 따옴표는 두 번 쓴다.

## 7. 필터
- 연도 다중 선택(기본 전체 선택). 요약·차트·표·CSV 모두 같은 필터 행 사용.
- 제외 행 목록은 필터와 무관하게 읽은 파일 전체의 검증 결과를 보여 준다.
- 정상 파일과 오류 파일은 섞지 않고 따로 확인(기본 샘플 = 정상 3개 파일).
